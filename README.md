# Universal Robots SDK for MATLAB

MATLAB loads the .NET library `UnderAutomation.UniversalRobots.dll` with `NET.addAssembly`. From MATLAB,
you can then use every interface of the SDK: RTDE, Primary Interface and URScript, Dashboard Server, REST
API, SSH and SFTP, kinematics.

This repository has no MATLAB package yet. To start:

1. Download `UnderAutomation.UniversalRobots.zip` from the [UniversalRobots.NET releases](https://github.com/underautomation/UniversalRobots.NET/releases).
   On Windows, unblock the zip file before you extract it (right-click, "Properties", "Unblock").
2. Follow the MATLAB page of the documentation: [Get started with MATLAB](https://underautomation.com/universal-robots/documentation/get-started-matlab).
   It explains how to load the DLL and connect to the robot. It also gives examples and the known limits.

- Product page: [underautomation.com/universal-robots](https://underautomation.com/universal-robots)
